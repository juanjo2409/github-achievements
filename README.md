## 🎖️ Catálogo de Logros

| Insignia | Nombre | Requisito principal | Estado |
| :---: | :--- | :--- | :---: |
| 🤠 | **Quickdraw** | Cerrar un Issue o Pull Request dentro de los primeros 5 minutos de haberlo abierto. | ✅ Desbloqueado |
| 🚀 | **YOLO** | Fusionar (merge) un Pull Request sin pasar por una revisión de código. | ✅ Desbloqueado |

## 🛠️ Cómo desbloquear cada insignia

### 1. 🤠 Quickdraw
- Abrir una Issue en cualquier repositorio público.
- Cerrarla inmediatamente (dentro de los primeros 5 minutos).

### 2. 🚀 YOLO
- Crear una rama (`feature/ejemplo`), hacer un commit y abrir un Pull Request a `main`.
- Fusionar el PR directamente sin solicitar ni recibir revisiones.

### 3. 👯 Pair Extraordinaire
- Crear un commit en una rama con el formato de coautor al final del mensaje:
  ```text
  git commit -m "feat: descripcion del cambio

  Co-authored-by: Nombre <email-de-usuario-github>"
  ```
- Abrir un Pull Request y fusionarlo a `main`.

### 4. 🦈 Pull Shark
- Abrir y fusionar al menos 2 Pull Requests en ramas de repositorios públicos.
